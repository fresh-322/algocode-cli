# algocode-cli

Клиент algocode.ru для терминала на Python 3.10+. Для разбиения условий нужна библиотека `pypdf`.

```sh
cd ~/algocode-cli
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./algocode-cli
```

Зависимости устанавливаются в виртуальное окружение проекта, что совместимо
с Python от Homebrew. Активация окружения не требуется: команда `algocode-cli`
сама запускает `.venv/bin/python`.

Введите номер курса, затем контеста и действия. `0` возвращает назад,
в главном меню — завершает программу. `Ctrl+C` также завершает программу.
Списки и ссылки загружаются с сайта при переходе на страницу.

Доступные действия: вывести ссылку с кнопки «Вход» и скачать файл
с кнопки «Условия». Если одной из кнопок нет, соответствующее действие
не предлагается. Контесты с «дистанционный тур», «дисттур» или «дистур»
в названии скрыты без учёта регистра. Сам раздел дистанционных туров
в главном меню сохранён.

По умолчанию условия сохраняются в `tasks-<имя текущей папки>` внутри текущей
директории. Например, при запуске из `~/study/graphs` задача A сохраняется
в `~/study/graphs/tasks-graphs/a.pdf`.
При повторном скачивании создаётся папка с суффиксом `-1`, `-2` и т. д.
Существующие файлы не перезаписываются: к имени добавляется номер.
При ошибке скачивания незавершённый файл удаляется.

После скачивания PDF автоматически разбивается по заголовкам «Задача A.»,
«Задача B.» и т. д. (также поддерживается «Problem A.»).
Файлы `a.pdf`, `b.pdf` и т. д. сохраняются прямо в папку задач.
Если задан `--download-dir`, задачи сохраняются в подпапке с именем исходного PDF.
Многостраничная задача сохраняется целиком: до начала следующей задачи.
Повторяющийся на страницах продолжения заголовок не создаёт новую задачу.
После успешного разбиения исходный PDF удаляется: остаются только файлы задач.
При ошибке разбиения исходный PDF сохраняется для повторной попытки.
Уже существующие папки не перезаписываются.

Разбиение рассчитано на текстовые PDF, в которых каждая задача начинается
с новой страницы. Если заголовки не распознаны или несколько задач начинаются
на одной странице, программа сообщает об этом и оставляет исходный PDF.

```sh
algocode-cli --download-dir ~/Downloads/algocode
algocode-cli --url https://algocode.ru/b2026/
```

Для команды `algocode-cli` создайте символическую ссылку в папке из `PATH`:

```sh
mkdir -p ~/.local/bin
chmod +x "$HOME/algocode-cli/algocode-cli"
ln -sfn "$HOME/algocode-cli/algocode-cli" "$HOME/.local/bin/algocode-cli"
```

Необходим доступ к интернету. Страницы с авторизацией или динамической
регистрацией можно открыть в браузере через меню страницы.
На macOS для HTTPS дополнительно загружаются системные корневые сертификаты
из `/etc/ssl/cert.pem`. Проверка сертификата сервера и имени хоста включена.
Парсер ориентируется на HTML-ссылки и карточки занятий; при изменении
структуры сайта может понадобиться его обновление.

Проверки: `.venv/bin/python -m unittest discover -s tests -v`.
